# 여름방학 체크리스트

날짜별로 생활 습관과 공부 기록을 남기는 웹 체크리스트입니다.

## 주요 기능

- 생활 습관 체크와 수학·독서·추가 활동 기록
- 하루 돌아보기, 별점, 확인 항목 기록
- 날짜별 기록 저장과 불러오기
- 달력에서 기록 확인 및 날짜 선택

## 파일 구성

- [index.html](index.html): 화면, 스타일, 동작이 함께 들어 있는 웹페이지입니다.

## 사용 방법

웹페이지에서 날짜를 선택하고 내용을 입력한 뒤 **오늘 기록 저장하기**를 누릅니다. 달력의 날짜를 누르면 해당 날짜의 기록을 불러와 수정할 수 있습니다.

기록은 Firebase Realtime Database에 저장됩니다. Firebase 모듈과 글꼴을 인터넷에서 불러오므로 인터넷 연결이 필요합니다.

## 수정할 때

- 실행 화면은 `index.html`에서 관리합니다.
- 현재 달력은 2026년 8월, 방학 기간은 2026년 7월 30일~8월 19일로 지정되어 있습니다. 다른 기간에 재사용하려면 관련 날짜 설정을 함께 확인합니다.
- 수정 후 날짜 선택, 기록 불러오기, 달력 표시를 확인합니다. 저장 기능 확인은 테스트용 데이터나 별도로 확인된 테스트 환경에서 진행합니다.
